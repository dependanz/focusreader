# Security policy

FocusReader is an early alpha. Security fixes are accepted for the latest code on the default branch.

Please avoid publishing exploit details before a fix is available. Use the repository's private security-advisory feature when it is enabled. If private reporting is unavailable, open a minimal issue asking the maintainer for a private contact channel without including sensitive details.

Useful reports include the affected FocusReader version, browser or Windows version, operating system, reproduction steps, impact, and any suggested mitigation.
